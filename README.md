# Interactive-5-Digit-OTP-Verification-with-Real-Time-Validation
Project Description

This project is a simple and interactive 5-digit OTP (One-Time Password) verification interface developed using HTML, CSS, and JavaScript. It provides a user-friendly way to enter and check a verification code.

How It Works

The user enters a 5-digit OTP into five separate input boxes. JavaScript automatically moves the cursor to the next box after each digit is entered and allows only numeric values. The user can click the Verify button to check whether all five digits have been entered. If the code is complete, the message "OTP Verified" appears. Otherwise, the system displays "Enter complete OTP". The Clear button resets all input fields and allows the user to enter a new code.

Technologies Used

HTML: Creates the OTP input fields and buttons.

CSS: Styles the user interface.

JavaScript: Handles OTP input, automatic focus, verification checks, and resetting
